# موقع الصفا للدعاية والإعلان

واجهة عربية متجاوبة مصمّمة أولًا للهاتف. تُقدّم الأعمال والخدمات والتواصل في صفحة واحدة. تعمل على GitHub Pages كملفات ثابتة بدون خادم تطبيق أو خطوة بناء.

## التشغيل محليًا

من جذر المشروع شغّل `python3 -m http.server 8000`، ثم افتح [الموقع المحلي](http://localhost:8000/) أو [لوحة الإدارة](http://localhost:8000/admin/). عند استخدام GitHub Pages يكون مسار اللوحة `/rrtn/admin/` على النطاق الحالي.

| الملف | المحتوى |
| --- | --- |
| `index.html`، `landing.css`، `landing.js` | الواجهة العامة والتفاعل وتحميل الوسائط والقياس |
| `landing-content.json` | عناوين الواجهة والخدمات والأعمال وبيانات القياس |
| `landing-schema.js` | فحص المحتوى ومساراته والمعرّفات المتكررة |
| `admin/` | لوحة تعديل الحقول ومعاينة المسودة وتصديرها |
| `assets/landing/` | أغلفة WebP، نسخ فيديو MP4 محلية مضغوطة، وخط Readex Pro وترخيصه |

## تحديث الأعمال والنصوص

1. افتح لوحة الإدارة وعدّل الحقول المطلوبة. لكل مشروع معرّف إنجليزي ثابت وصورة غلاف وملخص، ويمكن ترتيب وسائطه وإضافة صور وفيديو. تراجع اللوحة معرّفات المشاريع وعناوينها ومسارات الصور والفيديو حتى لا تتكرر.
2. للصور الجديدة، ارفعها إلى المستودع أولًا، واكتب المسار في اللوحة مثل `./assets/landing/new-cover.webp`. يمكن أيضًا استخدام رابط HTTPS عام مباشر من CDN. للغلاف المصغر أدخل عرضه الفعلي. استخدم WebP وصورة مصغرة 320–480 بكسل للهاتف، وMP4 H.264 مع `faststart` للفيديو القصير. أضف وصفًا بديلًا دقيقًا للنماذج ونصًا للفيديو، مع ملف ترجمة للفيديوهات التي تعتمد على الكلام قبل نشرها.
3. اضغط **معاينة المسودة** وراجع النتيجة من المتصفح نفسه. استخدم `?draft=1&variant=b` لمعاينة العنوان الثاني. تُحفظ آخر معاينة محليًا فقط. لإعادة استخدام الصفحة المنشورة بعد بدء مسودة، اضغط **إعادة تحميل المحتوى المنشور** في اللوحة.
4. اضغط **نسخ ملف المحتوى**، ثم **فتح محرّر GitHub**. استبدل نص `landing-content.json` بالكامل بالنص الجديد واختر فرعًا للمراجعة. بديلًا تستطيع تنزيل الملف واستبدال نظيره في المستودع. النشر يتم بالدمج إلى الفرع الذي يستضيفه GitHub Pages؛ حساب GitHub هو الذي يتحكم بصلاحية النشر.

## القياس وتجربة العناوين

- القياس متوقف إلى أن يضع المالك معرّف تدفق الويب `G-...` في اللوحة. الزائر يختار من **تفضيلات القياس** في التذييل. لا يُطلب Google Tag قبل الموافقة، ويمكن تعطيله من المكان نفسه.
- تعطيل **Enhanced Measurement** لتغيّرات سجل المتصفح والتمرير والنقرات الخارجية من إعدادات تدفق GA4 يمنع مضاعفة أحداث الصفحة والنقر المرسلة يدويًا. سجّل `experiment_id` و`headline_variant` و`section_id` و`click_location` و`project_id` كأبعاد مخصصة على مستوى الحدث عند الحاجة.
- الأحداث تشمل `section_view` و`project_open` و`video_start` و`video_complete` و`whatsapp_click` و`phone_click`. النقر على واتساب أو الهاتف إشارة اهتمام، وإتمام الحجز يحتاج قياسًا منفصلًا.
- عاين النسختين بإضافة `?variant=a` أو `?variant=b` إلى رابط الموقع. هاتان المعاينتان معزولتان عن القياس. عند تفعيل التجربة، يوزّع الموقع الزوار عشوائيًا بالتساوي نظريًا ويحتفظ بالاختيار في المتصفح عبر الزيارات. غيّر معرّف التجربة عند بدء مقارنة جديدة.
- قارن بين المجموعتين حسب نسبة الجلسات الموافقة على القياس التي شهدت نقرة واتساب أو اتصال إلى الجلسات ذات `headline_exposure`، مع تصفية معرّف التجربة. راقب رؤية المعرض وفتح المشاريع لمعرفة نقاط فقد الانتباه. حدّد حجم العينة ومدّة التجربة قبل نشرها حسب حركة الموقع والأثر المطلوب، ولا تحسم النتيجة من تقلبات أول الأيام.

## خطة التحقق قبل الإطلاق

| التجربة | معيار القبول |
| --- | --- |
| Safari على iPhone وChrome على Android فعليين | النص والأزرار ظاهرة بعرض 320–430 بكسل. شريط التواصل يحترم حافة الشاشة. معرض المشروع يفتح ويُغلق ويستعيد موضع المستخدم. |
| رابط التواصل على جهاز فعلي | يفتح واتساب رقم الصفا، ويظهر الرقم الصحيح في تطبيق الاتصال، ويعمل البريد. |
| اتصال بطيء بذاكرة تخزين فارغة | الواجهة تظهر أولًا والغلاف يتكيّف مع حجم الشاشة. لا تبدأ طلبات MP4 قبل الضغط على التشغيل. راجع LCP وCLS على النسخة المنشورة وكرّر القياس. أهداف المراجعة LCP ≤ 2.5 ثانية وCLS ≤ 0.1. |
| إتاحة الاستخدام | تنقّل بلوحة المفاتيح، اسم واضح لكل زر، إغلاق المعرض بـ Escape، وإيقاف الحركة عند تفعيل تقليل الحركة في النظام. |
| المحتوى والنشر | جرّب تعديل حقل ومعاينة المسودة، وجرّب إدخال معرّف مشروع أو مسار مكرر، وافتح كل الصور والفيديو في نسخة الكشف قبل الدمج. |
| GA4 وعناوين A/B | لا يُحمَّل الوسم عند الرفض. تحقّق من الأحداث ووسم النسخة في DebugView بعد ربط تدفقك، وعاين النسختين على الجهازين. |

للمرجع: [توثيق Google عن قياس مشاهدات الصفحة](https://developers.google.com/analytics/devguides/collection/ga4/views).
